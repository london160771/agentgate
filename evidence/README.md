# evidence/

Raw outputs from real runs on NEAR testnet. Nothing here is written by hand.

- `gate0.json`: written by `node scripts/gate0.js` (Manual Stop A).
- `attacks-<timestamp>.json`: written by `node scripts/attacks.js`.
- `seed-<timestamp>.json`, `owner-<timestamp>.json`, `agent-<timestamp>.json`: written by the other scripts.

Dry runs (`--dry-run`) never write here.
